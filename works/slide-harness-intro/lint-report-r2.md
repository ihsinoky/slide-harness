# lint-report-r2 — slide-harness 紹介資料（試走1号）ラウンド2

生成とは別パスの独立検査（ラウンド2）。判定基準：`core/anti-slop-checklist.md`、優先順位の正：`priority-map.md` v2（G0承認済み）、構成の正：`outline.md` v2（G1承認済み）。
対象はスライド本体 v2。ラウンド1（`lint-report.md`）の不合格項目が直っているかを特に確認した。
注記：スライド3のタイトル変更（「そのスライド」→「その資料」）は、生成側の変更メモに記録された G1承認タイトルからの意図的な変更として扱い、認知負荷の解消として判定した。
本レポートは検査のみを行い、スライド本体は修正していない。

## 総合判定：G2 パス

|---|---|---|

| 図中への文の詰め込み | スライド1、3 | 解消。スライド1のノードは「頼む」「即、圧縮」「優先順位のズレ」「成形」「戻れない」の短い部品名のみ。スライド3の表の文は対比の対象である実タイトルそのもの（値）であり、説明文の詰め込みではない |
| 「そのスライド」の対象が曖昧（認知負荷） | スライド3・タイトル | 解消。「その資料」に変更され、図・詳細が示す目次全体のコールドリードと対象が一致した |
| OK側の例が作り替えた短文で実物対比になっていない | スライド3・図 | 解消。主張文側は本資料の実タイトル（スライド1・2・5）をそのまま引用し、名詞題との対比になっている |

| 「3点の判断だけで作られた」が試走の実記録と不一致 | スライド6・内容 | 解消。「判断の中心は3点」「差し戻しの判断もゲートの中で行われる」「判断はその3つのゲートに集約された」と実記録（G0・G1での差し戻しはゲート内の判断）に合う表現に直された |
