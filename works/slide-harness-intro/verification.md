# verification — slide-harness 紹介資料（試走1号）

フェーズ3の成果物。対象は slides.md v2（lint ラウンド2で G2 パス）。

## コールドリード

タイトルだけを順に読む：
1. AIスライドができなかった原因は、生成能力ではなく、意図がずれたまま圧縮が始まることにある
2. slide-harnessは、優先順位マップを承認されるまで、要約も成形も始めない
3. タイトルだけ読んで話が通らなければ、その資料はまだ作る段階にない
4. 間違いは目次の段階で見つければ、直すのはその1行で済む
5. 作ったAIにそのまま採点させないので、「大幅に改善」のような根拠のない一文が残らない
6. あなたが決めるのは最初と目次と最後の3回だけで、間の作業は全部プロセスが引き受ける

判定：原因 → 手綱（G0）→ 構成の試し → 安い差し戻し → 別の検査 → 判断は3回、とでもチェーンどおりに話が通る。lint ラウンド1・2の全体項目でも両回パス。

注記：スライド3のタイトルは、lint ラウンド1の認知負荷の指摘を受けて G1 承認時の「そのスライド」から「その資料」に変更した。意味の変更ではなく対象の明確化。G3 でこの変更ごと確認を受ける。
