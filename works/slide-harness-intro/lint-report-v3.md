## 内容 lint
- 共通 anti-slop：パス。根拠のない数値なし（「試走3件」「7型」「4フェーズ」はいずれも core の実物に基づく）。中身のない言い換えの反復なし
- 主型⑥（説明・教育）：パス。前提の飛ばしなし（1枚目で基盤の定義から入る）。知識の目録化になっていない（疑問チェーンで接続）。単純化の誤り：6枚目の取り込みは「トークンのみ」と限界を注記で明示
- 副型②（ピッチ／招請）：パス。3枚目に理由と対策の対応（納得の入口）、11枚目に試し方（行動の入口）がある

## 視覚 lint（図解規約）
- 図の形はスライドごとに指定どおり描き分け（全体地図／流れ図／対応表／分類図／構造図／層図／手順図／実績の帯）。同一形状への寄せなし
- 図中の文字は部品名と短い注記のみ。四角は各図6つ以下（4枚目の7型一覧は分類図として例外的に7つ、ラベルは型名のみ）
- 対応の表現：3枚目は原因と対策を同じ行位置で対応づけ（対応表）。矢印での「対応」表現は使っていない
- 観察事項（不合格ではない）：印刷レンダリングではスライド下部に余白が出る（標準テンプレートの印刷 CSS の性質で、スライドショー表示には影響しない）
