# 図の形の分類（要約）

スライドごとに、言いたいこと1文 → 何を比べるか → 形、の順で選ぶ。形から先に決めない。
詳細な見本は figure-docs スキル（事業の図112種・開発の図38種）を参照。

## 数のある図（事業）

| 分類 | 使う場面 |
|---|---|
| 差 | 基準（0、目標、平均）からの上下 |
| 相関 | 2つ以上の値の関係。因果でなければ因果と書かない |
| 順位 | 値より並びの中の位置が大事なとき |
| 分布 | 値がどこにどれだけあるか、偏り |
| 時間での変化 | 傾向の変わり方 |
| 内訳 | 全体を部品に分ける |
| 大きさ | 数えた量の比較（率ではなく） |
| 地理 | 場所の違いが最も大事なときだけ |
| 流れ | 状態や場所の間を動く量 |

## 数が無い論点

位置づけ、構造と分け方、枠組み（SWOT等）、役割分担、手順と時間、関係、因果、確からしさ、優先と判断、前と後。

## 開発の図

構造（部品と依存）、やりとり（誰が誰に何を頼み何が返るか）、状態と手順（状態遷移と分岐）。

## 描き方の原則

- 見込みや推計は幅で描く（1つの値に見せない）
- 大きさは面積か長さ、確からしさは線の種類、関係の近さは距離、重みは線の太さ
- 図の中の文字は部品名・値・短い注記まで。文は図の下の要点1行へ
