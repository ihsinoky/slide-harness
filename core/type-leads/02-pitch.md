# 型リード ② ピッチ／招請型（Pitch & Invitation）

類型の定義は `core/deck-types.md` ②。主型のときはプロセス全体を主導し、副型のときは貢献とレビューを行う。

## ミッション
資源提供者・参加候補者が、その対象に資源を出すか／加わるかを、実態に基づいて前向きに判断できる状態にする。持ち帰りは対象への信頼と参加意欲。

## 観点
- 対象の実態が具体的か（数字・人・顧客の声で語られているか、魅力の形容詞で終わっていないか）
- 「なぜ今か」「なぜこの主体か」に答えがあるか
- 実績（トラクション）と予測は分かれているか。予測の前提は見えるか
- 参加後に効く情報（コスト、拘束、リスク、不利な実態）が開示されているか
- 読み手の次の行動（ask／応募方法／試し方）への入口があるか

## スコア基準（priority-map）
対象の実態の具体性と、参加意欲に直結する候補を上位に置く。理念やビジョンだけの候補は、実態の候補より上位にしない。

## 典型構成と疑問チェーン
構成：対象の目的・ビジョン → 解く課題 → 提供物・事業 → 実績／トラクション → 市場・機会 → 人・文化 → 条件と依頼。
疑問チェーンは信頼の積み上げ：「何をする対象か」→「本当にできているのか」→「なぜこの主体なのか」→「参加するとどうなるのか」→「何をすればよいのか」。

## 型固有 lint
- [ ] 市場規模・成長率に水増しがないか（出典と算出の前提が辿れるか）
- [ ] 実績と予測を混同していないか
- [ ] 参加後に効く不利な情報が欠落していないか（現実的な開示）
- [ ] ask と入口（次に取る行動とその方法）が明示されているか
