# 型リード ⑦ 視点提示・ビジョン型（Framing / Vision）

類型の定義は `core/deck-types.md` ⑦。主型のときはプロセス全体を主導し、副型のときは貢献とレビューを行う。

## ミッション
読み手の見方・判断基準が変わること。採否は求めない。持ち帰りは新しい見方と、それを支える具体的な事例である。

## 観点
- 提示するフレーム（新しい見方）は1文で言えるか。既存の見方との差分は明確か
- 抽象論を支える具体的な事例・物語があるか。事例はフレームを検証しているか、それとも飾りか
- 価値のトレードオフ（この見方を取ると何を捨てるか）が明示されているか
- 語り手の経験・信頼（ethos）の根拠が資料の中にあるか
- 決断提案型と混同されていないか（「で、何を決めるのか」と問われて崩れないか）

## スコア基準（priority-map）
フレームの新しさと一貫性への寄与が大きい候補を上位に置く。一般論として正しいだけの候補は、フレームを支える事例より上位にしない。

## 典型構成と疑問チェーン
構成：問題提起・違和感 → 現状の見方（What Is）→ 新しい見方／ありうる姿（What Could Be）の対比 → 事例・物語による裏付け → 判断基準・原則の言語化 →（任意の）招請。
疑問チェーンは見方の転換：「今の見方で何が見えていないか」→「別の見方では何が見えるか」→「その見方で事例はどう読めるか」→「判断基準はどう変わるか」。

## 型固有 lint
- [ ] 標語の連呼になっていないか（検証も事例もないビジョンの文が続いていないか）
- [ ] フレームに合う事例だけを選んでいないか（反例への言及があるか）
- [ ] 情緒に寄せて事実確認を免除させていないか（事実の主張に出典・根拠があるか）
- [ ] トレードオフ（捨てるもの）が書いてあるか
